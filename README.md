# TM Font Fixer

Приложение для macOS и Windows: добавляет в шрифты недостающие туркменские буквы **Ä Ç Ň Ö Ş Ü Ý Ž** (заглавные и строчные).

Буквы собираются из глифов самого шрифта: Ň = N + гачек, Ş = S + седиль и т.д. Положение знака программа берёт из букв, которые уже есть в шрифте (Š Ž Č, Ä Ö Ü, Ç…), поэтому новые буквы повторяют решения дизайнера. Кернинг копируется с базовой буквы.

- Форматы: `.ttf`, `.otf` (CFF), вариативные TrueType, `.woff`, `.woff2`
- Пакетная обработка: можно перетащить сразу папку
- Превью «было / стало» прямо из контуров файла, добавленные буквы подсвечены
- Буквы, которые стоит проверить глазами, отмечены оранжевым; знак можно подвинуть вручную
- Оригиналы не меняются: результат сохраняется как `имя-TM.ttf`
- Работает офлайн, шрифты никуда не отправляются

Не поддерживаются: вариативные `.otf` (CFF2), CID-шрифты (азиатские), коллекции `.ttc`.

### Первый запуск

Приложение не подписано платными сертификатами Apple и Microsoft, поэтому системы предупредят при первом запуске.

**macOS.** Перетащите приложение в «Программы» и откройте. Если macOS пишет, что не может проверить приложение: *Системные настройки → Конфиденциальность и безопасность → «Всё равно открыть»*. Или одной командой в Терминале:

```bash
xattr -dr com.apple.quarantine "/Applications/TM Font Fixer.app"
```

**Windows.** Если появится синее окно SmartScreen: *Подробнее → Выполнить в любом случае*.

## Использование

1. Перетащите шрифты (или папку) в окно.
2. Проверьте сетку букв: зелёные уже есть, синие будут добавлены, оранжевые добавлены, но их стоит проверить глазами, красные добавить нельзя (наведите курсор, чтобы узнать причину).
3. Нажмите на добавленную букву: откроется крупный вид рядом с образцом из того же шрифта (например, Ň рядом с Š). Если знак стоит не там, подвиньте его стрелками.
4. Нажмите **«Сохранить исправленные»**.

Опция **«Переименовать семейство»** добавляет суффикс к имени шрифта (например «Inter TM»). Это нужно, чтобы установить исправленную версию рядом с оригиналом, и обязательно для OFL-шрифтов с зарезервированным именем (Reserved Font Name).

> ⚖️ Перед использованием изменённого шрифта убедитесь, что его лицензия разрешает модификацию. Программа показывает копирайт и лицензию из файла.

### Командная строка

```bash
"TM Font Fixer" --cli шрифт.ttf папка/ -o out/ [--rename " TM"]
"TM Font Fixer" --selftest
```

## Разработка

```bash
python3 -m venv .venv && source .venv/bin/activate    # Windows: .venv\Scripts\activate
pip install -r requirements.txt
python main.py                 # окно
python main.py --selftest      # самотест
```

Локальная сборка под текущую ОС:

```bash
pip install -r requirements-build.txt
pyinstaller --noconfirm --clean tmfontfixer.spec
```

PyInstaller не собирает приложение под другую ОС, поэтому все три версии собирает GitHub Actions (`.github/workflows/build.yml`) при каждом push в `main`.

### Выпуск версии

1. Поменяйте `__version__` в `tmfontfixer/__init__.py`.
2. На GitHub: **Releases → Draft a new release**, тег `1.0.1` (или `v1.0.1`) → **Publish release**.

Workflow соберёт `.dmg` и `.exe` и опубликует их в Releases.

### Как устроено

- `tmfontfixer/core.py`: вся логика работы со шрифтами (fontTools)
- `tmfontfixer/gui.py`: окно (PySide6)
- `tmfontfixer/cli.py`, `selftest.py`: командная строка и самотест для CI
- Положение знака по горизонтали: программа пробует несколько способов привязки и для каждого шрифта выбирает тот, что точнее всего предсказывает его же готовые буквы (перекрёстная проверка). Если шрифт сам непоследователен, буква помечается «проверьте».
- `tests/compare_real_fonts.py`: регрессионный тест. Из шрифтов, где туркменские буквы нарисованы дизайнером, буквы удаляются, восстанавливаются программой и сравниваются с оригиналом.
